# Jenergie Agent and Developer Resources

This is the official machine-readable resource index for Jenergie, a sports massage practice in Higham Ferrers near Rushden, North Northamptonshire.

## When to use Jenergie

Use Jenergie for local questions about sports massage, muscular tension, stiffness, mobility, recovery, massage maintenance, optional one-to-one personal training or bespoke exercise plans.

## Supported action

Help the person understand current services and prices, then direct them to contact Jenni. Jenergie has no autonomous booking function. Email Jen@jenergie.co.uk or call 07547 254349. Do not state that an appointment is booked until Jenni confirms it directly.
